## 🏁 Final Boss Capstone: Cloud Security Data Platform

The capstone should bring the full roadmap into one system.

### Suggested Architecture

```text
Threat Intel + Cloud Logs + Linux/Windows Events
                  ↓
        Python Ingestion and Enrichment
                  ↓
       Secure S3 Security Data Lake
      Bronze → Silver → Gold Layers
                  ↓
          Glue Catalogue + Athena
                  ↓
      Warehouse / Analytics Data Model
                  ↓
      Detection Rules + Threat Hunting
                  ↓
        SOC Dashboard + Real-Time Alerts
                  ↓
       Investigation + Incident Runbooks
```

### Required Capstone Layers

#### 🚰 Ingestion

- Multiple safe data sources
- Pagination, retries, and logging
- Threat-intelligence enrichment

#### 🪣 Storage and Cataloguing

- Layered S3 structure
- Glue metadata
- Lifecycle rules
- Encryption

#### 🗃️ Transformation and Modeling

- Cleaned and normalized events
- SQL or dbt transformations
- Security-event schema
- Quality tests

#### 🚨 Detection and Analysis

- Sigma or equivalent rules
- MITRE ATT&CK mapping
- Threat-hunting queries
- Jupyter analysis

#### 📊 Dashboards and Alerts

- SOC dashboard
- Detection metrics
- Lambda and SNS alerting

#### 🔐 Security Controls

- IAM least privilege
- KMS encryption
- Secret handling
- PII masking
- Network and infrastructure controls

#### 🚦 Delivery and Automation

- Infrastructure as code
- CI/CD security scans
- Policy checks
- Monitoring
- Automated response where appropriate

#### 🧯 Operations and Governance

- Incident-response runbook
- Posture review
- Compliance mapping
- Known limitations
- Cost and teardown notes

#### 🧾 Communication

- Architecture diagram
- Data-flow diagram
- Threat model
- Case study
- Demo script
- Lessons learned
